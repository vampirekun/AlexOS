# Jira update

Use this playbook to communicate meaningful engineering progress in a work
item. The outcome is a concise, factual record that another engineer or
stakeholder can act on.

## Procedure

1. Lead with the current outcome or state.
2. State completed work and its relevant effect, not a transcript of activity.
3. State current or next work when the item remains open.
4. Identify blockers, decisions, dependencies, or risks that require attention.
5. Include validation or evidence when it changes confidence in the result.
6. Remove repetition already obvious from the ticket unless it provides needed
   context.

Apply the [`communication policy`](../policies/communication.md) and any
relevant tone preference from [`../context/people/`](../context/people/README.md).
