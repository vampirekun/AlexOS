# Scrum update

Use this playbook for a short daily progress update. The outcome is a natural,
non-repetitive summary of progress, next intent, and impediments.

## Procedure

1. Summarize the meaningful result since the previous update.
2. State today's intended outcome rather than listing every planned action.
3. Name blockers or dependencies that require help; otherwise state that there
   are none only when the format expects it.
4. Mention risk or changed direction when the team needs to adapt.
5. Keep detail proportional to a spoken update and avoid ticket-history
   narration.

Apply the [`communication policy`](../policies/communication.md) and relevant
preferences from [`../context/people/`](../context/people/README.md).
