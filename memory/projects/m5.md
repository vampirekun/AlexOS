# M5

This memory applies when work involves the M5 repository family. It supplies
project-specific vocabulary and constraints without changing the universal
AlexOS operating model.

## Repository family

Frequently used repositories include:

- `M5.ClientUI`
- `M5.ClientUI.Content`
- `M5.ClientUI.ShellCore`

## Common domains and infrastructure

Recurring areas include Cardless, SignalR, Redis, Kubernetes, Helm, Jenkins,
Grafana, Prometheus, and Loki.

## Project constraints

- Preserve compatibility across the repository family.
- Prefer established abstractions and integration patterns.
- Validate changes in development before advancing them to QA when the delivery
  path permits it.

For implementation work, select the
[`software-change playbook`](../../playbooks/software-change.md) or a more
specialized procedure. These facts do not replace inspection of the active
repository and its own guidance.
