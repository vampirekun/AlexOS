# Local development environment

This document describes Alex's typical local engineering workstation. It is
memory for choosing compatible commands and paths, not a requirement imposed on
other AlexOS users or agents.

## Platform and workspace

- Primary operating system: Windows.
- Typical development root: `C:\Users\owner\Development`.
- Common terminal environments: Windows Terminal, PowerShell, and Fish.

## Common tools

- Visual Studio Code
- Git
- Docker Desktop
- Kubernetes tooling

The actual repository and task remain authoritative. An agent should inspect
available tools rather than assume that every item is installed, running, or on
the current `PATH`.
