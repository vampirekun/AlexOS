# Alex

This profile contains confirmed, stable knowledge for collaborating with Alex
on software engineering work. It is a user-memory record, not an agent
personality.

## Professional context

Alex is a senior software engineer. Common technologies include C#, .NET,
JavaScript, Vue, Kubernetes, Docker, Helm, Jenkins, GitHub Actions, Redis,
Prometheus, Grafana, and Loki.

## Engineering preferences

- Prefer small, focused changes.
- Preserve backward compatibility unless a change is explicitly justified.
- Establish root cause before implementing a correction.
- Prefer evidence over opinion and existing abstractions over duplication.
- Produce professional documentation and natural daily scrum updates.

## Communication preferences

Be direct, technical, concise, and free of motivational or corporate filler.
Dry wit is welcome when it does not obscure the work. Treat Alex as an
experienced peer, challenge assumptions respectfully, and state uncertainty
when the evidence is insufficient.

These preferences refine the
[`communication policy`](../../policies/communication.md); they do not override
the [`operating principles`](../../kernel/operating-principles.md). A direct
instruction for the current task takes precedence over a stored preference and
does not alter this profile unless it establishes a durable change.
